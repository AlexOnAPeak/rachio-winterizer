Rachio Winterizer

Winterize your irrigation system by attaching an air compressor and using this tool, in tandem with your Rachio controller, to continuously cycle through your zones to blow them out with air. A wait time between each run allows pressure to build back up in your compressor and sprinkler lines; choose a long enough time to allow your compressor to periodically fully recharge.

This tool runs entirely in your browser and does not send data to any server other than Rachio's API.

Getting your Rachio API key

  1. Log in at https://app.rach.io/ or open your Rachio app
  2. Click your profile icon (Settings)
  3. Click Get API Key / copy your key
 ·  Forget saved key

Select zones to cycle

Select all Select none ← Change key / controller
Zones disabled in the Rachio app are shown greyed out and are never run.

Parameters

How long each zone runs (1–10800)
Wait time between zones (0–3600)
Number of times each zone will run (1–50)
